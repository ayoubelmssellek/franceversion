# Plan des mots-clés image (MeilleurIPTVFrance)

**Marché :** France · langue `fr-FR`  
**Règle :** chaque image reçoit des expressions qui correspondent à **sa page**. Ne pas coller la même liste sur chaque fichier.

## Ce que chaque image porte

1. Nom de fichier en français
2. `alt` du site (HTML)
3. Mots-clés injectés dans le fichier (EXIF / IPTC / texte PNG)
4. Une ligne dans `seo-ops/image-keyword-assignments.json`

## Où vont les expressions principales

Les grands termes (`iptv france`, `meilleur iptv france`, `acheter iptv france`) vont sur le hero, l’image Open Graph et les couvertures principales du blog.

- Les emplacements de chaînes françaises n’ont pas encore de logo. Les fichiers internationaux (sport, films, paiements) portent `IPTV France`.
- `payments/*` → nom de la marque + IPTV France
- Affiches de films et de séries → titre + IPTV France
