# SEO Rules

## General

- Every new page must target a unique search intent.
- Avoid keyword cannibalization.
- Never duplicate content.
- Every page should have a clear purpose.

---

## Titles

- Every page must have a unique SEO title.
- Titles should naturally include the primary keyword.
- Keep titles under 60 characters.

---

## Meta Description

- Every page must have a unique meta description.
- Keep between 140–160 characters.
- Encourage clicks without keyword stuffing.

---

## Headings

- Only one H1 per page.
- Use H2/H3 logically.
- Heading structure must reflect content hierarchy.

---

## Internal Linking

- Link to relevant pages naturally.
- Add contextual internal links whenever appropriate.
- Vary anchor text.
- Never over-optimize anchor text.

---

## Images

- Every image must include descriptive ALT text.
- Optimize filenames for SEO.
- Lazy-load non-critical images.

---

## URLs

- Keep URLs short and descriptive.
- Use lowercase.
- Use hyphens instead of underscores.

---

## Structured Data

Implement Schema.org whenever appropriate:
- Article
- Product
- FAQ
- Breadcrumb
- Organization
- LocalBusiness
- Service
- Review

---

## Technical SEO

- Every indexable page must have a canonical URL.
- Prevent duplicate canonical tags.
- Ensure pages are included in sitemap.xml.
- Avoid broken links.
- Avoid redirect chains.

---

## Content

- Write for users first.
- Follow Google's Helpful Content guidelines.
- Demonstrate expertise and authority.
- Do not create thin or AI-spam content.

---

## Performance

- Optimize Core Web Vitals.
- Compress images.
- Minimize JavaScript.
- Use lazy loading where appropriate.

---

## Before Every Commit

Check:

- Missing H1
- Missing title
- Missing meta description
- Missing ALT text
- Broken internal links
- Duplicate metadata
- Canonical issues
- Schema validation
